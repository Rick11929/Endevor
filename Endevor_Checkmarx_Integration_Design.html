Endevor Mainframe Code Integration Design for Checkmarx SAST Scanning

Version: 1.0 | Date: May 28, 2026 | Author: Grok (Cyber SAST SME Support)

1. Objective

Design a reliable, automated, and scalable solution to periodically extract source code (Elements) from multiple Endevor-managed Mainframe applications and perform SAST scanning using Checkmarx.

2. Scope

  • Support 10+ Mainframe Applications stored in Endevor.
  • Use Python + Endevor REST API v2 as the primary integration method.
  • Periodic scanning (daily / weekly).
  • Cover mainframe languages: COBOL, COPYBOOK, PL/I, JCL, etc.
